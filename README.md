# 🚗 AutoService - Oto Servis Yönetim Sistemi

AutoService, oto servis süreçlerinin dijital ortamda yönetilmesi amacıyla geliştirilmiş **ASP.NET Core MVC** tabanlı bir web uygulamasıdır.

Proje; katmanlı mimari yapısı kullanılarak geliştirilmiş ve veritabanı işlemlerinde **Entity Framework Core** ile **Microsoft SQL Server** kullanılmıştır.

## 🛠️ Kullanılan Teknolojiler

* C#
* .NET / ASP.NET Core MVC
* Entity Framework Core
* Microsoft SQL Server
* HTML
* CSS
* Bootstrap
* Git / GitHub

## 🏗️ Proje Mimarisi

Proje, sorumlulukların ayrılması ve daha sürdürülebilir bir kod yapısı oluşturulması amacıyla katmanlara ayrılmıştır.

* **AutoService.Entity** — Veritabanı varlıklarının ve modellerin bulunduğu katman
* **AutoService.DataAccess** — Veritabanı işlemlerinin gerçekleştirildiği veri erişim katmanı
* **AutoService.Business** — İş kurallarının yönetildiği katman
* **AutoService.Dto** — Katmanlar arasında veri aktarımı için kullanılan DTO sınıfları
* **AutoService.Web** — ASP.NET Core MVC kullanıcı arayüzü ve web uygulaması

## ✨ Projede Uygulanan Yapılar

* CRUD işlemleri
* Katmanlı mimari
* Entity Framework Core ile veritabanı yönetimi
* Microsoft SQL Server entegrasyonu
* Dependency Injection
* DTO kullanımı
* ASP.NET Core MVC yapısı

## 🎯 Projenin Amacı

Bu proje ile gerçek bir oto servis yönetim senaryosu üzerinden ASP.NET Core MVC, Entity Framework Core, SQL Server ve katmanlı mimari konularında uygulamalı deneyim kazanılması amaçlanmıştır.
